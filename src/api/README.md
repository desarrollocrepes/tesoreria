# API

Esta carpeta contiene los servicios y funciones para comunicarse con el backend.

## Estructura sugerida:
- `cliente.js` - Configuración del cliente HTTP (axios, fetch)
- `autenticacion.js` - Servicios de login, logout, registro
- `caja.js` - Servicios relacionados con operaciones de caja
- `reportes.js` - Servicios para generar reportes
